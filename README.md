# 유가증권시장 공시성 보도 알림 서비스

30개 신문사 RSS를 수집해, 상장사 관련 공시성 키워드(78종) 보도를 하루 3회(오전 06:20 / 오후 13:00 / 14:20 KST) 이메일로 발송합니다. GitHub Actions에서 완전 무료·무인 자동 실행됩니다. 외부 파이썬 패키지가 필요 없습니다(표준 라이브러리만 사용).

## 핵심 사양
- 대상 매체: 30개사 (가판/디지털가판 제외, 정상연동 18곳 + 검증대상 12곳)
- 검색 키워드: 78종 (공시규정 제7조 분류 매핑)
- 매칭 규칙: "회사명 + 키워드 동시 등장" (정밀 필터로 부분일치 오탐 제거)
- 상장사 판정: KIND 상장법인 목록 자동 로딩 (API 키 불필요)
- 공시 대조: 각 회사 DART/KIND 공시검색 링크 자동 첨부
- 태그: 미공시 의심 / 공시확인 필요 / 공시확인
- 수집 구간: 기사 최초 배포시각(pubDate) 기준, 세 구간이 이어져 무누락
    - 오전(06:20): 전영업일 14:20 ~ 당일 06:20 (주말 공백까지 커버)
    - 오후1(13:00): 06:20 ~ 13:00
    - 오후2(14:20): 13:00 ~ 14:20

## 파일 구성
| 파일 | 역할 |
|---|---|
| feeds.py | 30개사 RSS 목록(ok/verify) + 네이버 우회 oid |
| keywords.py | 키워드 78종 + 공시분류 매핑 |
| listed.py | KIND 상장사 목록 자동 다운로드/캐시 |
| matcher.py | 회사명+키워드 정밀 매칭 필터 |
| naver_fallback.py | RSS 실패 매체 네이버 언론사홈 우회 수집 |
| disclosure.py | 상장 판정 + 공시링크/태그 부여 |
| collect.py | 30분 폴링 수집 → store.json 누적 |
| notify.py | 구간 필터 → 매칭 → 태깅 → Gmail 발송 |
| check_feeds.py | verify 매체 RSS 살아있는지 점검 |
| .github/workflows/poll-collect.yml | 30분마다 수집·상태 커밋 |
| .github/workflows/send-alert.yml | 06:20/13:00/14:20 발송 |

## 설치 (약 10분, 준비물 Gmail 계정 하나)

### 1) GitHub 공개(Public) 저장소 생성
공개 저장소여야 Actions 실행이 무제한 무료입니다. 이 폴더의 모든 파일을 업로드(push)합니다.

### 2) Gmail 앱 비밀번호 발급
1. Google 계정 → 보안 → **2단계 인증**을 켭니다(필수).
2. 보안 화면 검색창에 **앱 비밀번호** 검색 → 진입.
3. 앱 이름(예: news-alert) 입력 → 생성 → **16자리** 비밀번호를 복사(공백 제거).
- 이 16자리는 SMTP 전용 비밀번호이며 OAuth 토큰이 아닙니다.

### 3) 저장소 Secrets 등록
저장소 → Settings → Secrets and variables → Actions → New repository secret 로 아래 3개 등록:
| 이름 | 값 |
|---|---|
| GMAIL_USER | 보내는 Gmail 주소 (예: me@gmail.com) |
| GMAIL_APP_PW | 위에서 발급한 16자리 앱 비밀번호 |
| MAIL_TO | 받는 주소(여러 명은 콤마로 구분) |

(선택) DART_API_KEY 를 등록하면 "미공시 의심" 자동판정으로 업그레이드됩니다. 없어도 링크 방식으로 정상 동작합니다.

### 4) 동작 확인
- Actions 탭 → send-alert → Run workflow(slot=morning) 로 수동 1회 테스트.
- 메일이 오면 완료. 이후 정해진 시각에 자동 발송됩니다.

## verify 매체 RSS 최종 확정 (선택, 인터넷 PC에서)
검증대상 12곳의 RSS 주소는 후보 주소입니다. 인터넷 되는 PC에서 한 번만:
```
python check_feeds.py
```
- [OK] : 그대로 사용
- [DEAD->NAVER] : 자동으로 네이버 우회 수집됨(문화일보·아시아투데이·뉴스토마토·내일신문·부산일보·국제신문)
- [DEAD] : feeds.py 의 해당 url 을 실제 주소로 교체

교체하지 않아도 서비스는 동작하며, 빠진 매체는 메일 하단 "수집 매체 현황"에 표시됩니다.

## 참고/한계
- RSS는 최신 수십 건만 노출 → 30분 폴링으로 store.json에 누적해 무누락 보장.
- GitHub 예약 실행은 서버 혼잡 시 수 분 지연될 수 있음.
- 공개 저장소는 60일간 커밋이 없으면 예약이 비활성화됨 → 폴링 커밋이 자동으로 활동을 유지함.
- 네이버 우회는 공개 언론사홈 파싱 방식으로, 페이지 구조 변경 시 파서 보정이 필요할 수 있음.
